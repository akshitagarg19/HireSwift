# Staff Frontend Engineer & React Lead

**Location**: Gurugram / Noida, India (Hybrid / Remote Option)  
**Department**: Frontend Engineering  
**Experience Level**: 4-8 Years  

### Job Summary
Looking for a visionary Frontend Technical Lead to spearhead our next-generation web platforms. You will establish frontend architectural standards, optimize web vitals (LCP, FID, CLS), and mentor a team of engineers building accessible, performant React applications.

### Key Requirements
- **Required Skills**: React, TypeScript, Next.js, Tailwind CSS, State Management (Zustand/Redux), Web Performance
- **Preferred Skills**: GraphQL, Webpack/Vite optimization, Playwright/Cypress, Micro-frontends, Radix UI
- **Experience**: Minimum 4 years of dedicated modern frontend development with at least 1 year in a technical leadership capacity.
- **Education**: B.Tech / B.E. / MCA in Computer Science with minimum 7.0 CGPA or 70%.
- **Responsibilities**:
  - Architect enterprise design systems with Tailwind CSS, accessible primitives, and fluid animations.
  - Optimize client-side bundles and asset caching strategies to achieve sub-second page loads.
  - Champion test-driven frontend engineering with unit, integration, and E2E test suites.
  - Collaborate with product designers and backend engineers to define API contracts and telemetry.
