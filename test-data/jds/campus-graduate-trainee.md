# Campus Graduate Trainee - Engineering (2024 / 2025 Batch)

**Location**: Pune / Bengaluru, India (On-site)  
**Department**: Campus Early Careers  
**Experience Level**: Fresher (0-1 Year)  

### Job Summary
Our early careers campus recruitment program hires top engineering graduates across India to join our accelerated software engineering rotational track.

### Key Requirements
- **Required Skills**: Python, C++, Data Structures, Algorithms, SQL
- **Preferred Skills**: Git, Linux, Web Development basics (HTML/CSS/JS)
- **Academic Cutoffs**:
  - Minimum 10th Standard: 80%
  - Minimum 12th Standard: 80%
  - Minimum Engineering CGPA: 8.0 / 10.0
  - Graduation Year: 2024 or 2025 graduating batch
- **Eligible Degrees**: B.Tech, B.E., M.Tech in CS, IT, ECE, EE.
- **Responsibilities**:
  - Complete a 12-week comprehensive engineering bootcamp.
  - Work alongside senior engineering mentors on production codebase.
  - Participate in code reviews, bug fixes, automated test suites, and internal hackathons.
